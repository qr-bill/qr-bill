# Reference QR code encoder

`qrcodegen.ts` is the QR Code generator library of [Project Nayuki](https://www.nayuki.io/page/qr-code-generator-library), TypeScript version, copied **unmodified** from [nayuki/QR-Code-generator](https://github.com/nayuki/QR-Code-generator/blob/9a217d443937f60cc56c1458c39a211d7f2d3af5/typescript-javascript/qrcodegen.ts) at commit `9a217d4`. It is distributed under the MIT License; its notice is at the top of the file.

The encoder of `@qr-bill/core` (`packages/core/src/qr-code/`) is adapted from it and reduced to what the Swiss QR Code needs. The tests encode the same contents with both and require the same modules, mask included: the proof that the reduction changed nothing.

**Do not edit this file.** It is excluded from linting, formatting and type checking, and a test checks that its git blob hash is still the one of the upstream file. To update it, copy the new upstream version as is and update the commit and the hash in `../reference.ts` and here.
